recon.py

Mini ferramenta de reconhecimento — WHOIS, DNS, subdomínios e port scan numa cadeia só.

recon.py automatiza a primeira fase de qualquer pentest ou investigação OSINT: descobrir o que existe sobre um domínio antes de tocar em qualquer coisa mais invasiva. Junta numa ferramenta só o que normalmente seria feito com vários comandos separados — whois, dig, brute-force manual de subdomínio, nmap — e organiza tudo em relatório no terminal e em JSON.

Fluxo de execução

WHOIS → DNS Enum → Subdomain Enum → Port Scan → Resumo de risco

O que cada etapa faz

1. WHOIS lookup passivo

Consulta o registro público do domínio: registrar, data de criação, data de expiração, nameservers e e-mails de contato. Ponto de partida clássico — só olha dados já públicos.

2. DNS enumeration passivo

Resolve os principais registros: A/AAAA (IPs), MX (e-mail), TXT, NS, CNAME, SOA. Se o dnspython não estiver instalado, cai num fallback básico só com A record via socket.

3. Subdomain enumeration crt.sh passivo brute-force ativo

crt.sh (Certificate Transparency) — consulta os logs públicos de certificados SSL emitidos para o domínio. Não toca no alvo, só olha um banco público.

Brute-force com wordlist — testa palavras (www, admin, dev...) na frente do domínio e vê o que resolve via DNS. Ativo, mas simples e multi-thread.

4. Port scan ativo — flag --scan-ports

Roda nmap -sV só nos subdomínios que realmente resolveram. Usa python-nmap se disponível, ou cai pro binário nmap via subprocess. Detecta versão de serviço, não só porta aberta.

5. Resumo de risco automático

Cruza as portas abertas com uma lista de portas classicamente perigosas de estarem expostas (RDP, SMB, FTP, Telnet, bancos de dados, VNC) e explica o motivo do risco de cada uma. Roda sozinho junto com o port scan.

Instalação

sudo dnf install nmap
pip install requests dnspython python-whois python-nmap --break-system-packages

dnspython e python-whois são opcionais — o script tem fallback pras duas. Mas pra usar 100% das features, instala tudo.

Como usar

Recon básico (WHOIS + DNS + crt.sh)

python3 recon.py -d exemplo.com

Com brute-force de subdomínio

python3 recon.py -d exemplo.com -w subdomains-small.txt

Fluxo completo — subdomínios + port scan + risco + JSON

python3 recon.py -d exemplo.com -w subdomains-small.txt --scan-ports -o resultado.json

Flags disponíveis

FlagDescrição
-d, --domainDomínio alvo (obrigatório)
-w, --wordlistWordlist para brute-force de subdomínio
-o, --outputSalva o resultado completo em JSON
-t, --threadsThreads do brute-force (padrão: 20)
--no-crtshPula a consulta ao crt.sh
--scan-portsAtiva o port scan nos subdomínios resolvidos
--portsLista de portas a escanear (padrão: mais comuns)
--scan-threadsThreads do port scan (padrão: 5)

Sobre a wordlist incluída

subdomains-small.txt é uma lista pequena de exemplo/teste — 30 palavras comuns. Serve pra validar que o script funciona. Pra recon sério, use wordlists maiores como as da SecLists.

⚠ Uso responsável

WHOIS e crt.sh são passivos — só consultam bancos públicos, não tocam na infraestrutura do alvo.

Brute-force de subdomínio e port scan são ativos — geram tráfego direto contra a infraestrutura de terceiros. Só rode contra:

  • Domínios/infraestrutura que você possui
  • Labs de prática (TryHackMe, HackTheBox, etc)
  • Alvos com escopo de autorização assinado (bug bounty, pentest contratado)

Fazer isso contra domínio de terceiros sem autorização é ilegal na maioria das jurisdições — inclusive em Angola.
